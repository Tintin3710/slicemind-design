# 제품 공통 맥락

상태: 사용자 설명과 기존 장표를 바탕으로 사후 정리한 초안.

## 사용자 역할

- 보호자: 환자에 맞는 간병인을 찾고, 지원자를 비교·선택하고, 비용과 다음 행동을 확인한다.
- 간병인: 공고에 지원하고, 담당 환자와 업무를 확인하고, 간병 기록을 작성한다.

## Care Case

하나의 간병 요청부터 종료까지를 공통 단위로 정의한다.

간병 요청 → 모집 중 → 선택 대기 → 매칭 완료 → 결제 완료 → 간병 중 → 기록 완료

- 매칭 실패: 간병비 조정 → 재신청 경로를 제공한다.
- 취소: 취소 시점·진행 상태에 따른 정책과 금전적 영향을 확인하도록 한다.
- 한 앱의 행동이 다른 앱의 상태에 미치는 영향은 기능 명세에서 연결한다.

## 기존 경험의 확인 범위

전담 PM 없이 서비스 흐름과 정책을 기획하고 UX/UI를 설계했다. 수익 관련 정책과 위약금 비율 결정은 본인의 범위에서 제외된다. 기존 보호자 3명의 개선안 재사용에서 긍정적 정성 반응을 받았다. 디자인·QA 완료 후 경영 측 정책 이슈로 출시 대기 상태였으며, 실제 운영 지표는 확인하지 못했다.

이번 저장소의 재현 결과를 원래 프로젝트 당시의 결과로 소급하지 않는다. 현재 구현·검증 여부는 각 기능과 검증 문서에서 확인한다.
