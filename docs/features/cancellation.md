# 취소·위약금·환불 안내

상태: 기능 문서 골격. 수익 정책·위약금 비율은 확정하지 않음.

## 사용자 질문

지금 취소하면 어떤 제한이 적용되고 얼마를 돌려받는가?

## 정리할 케이스

| 구분 | 필요한 확인 | 현재 상태 |
|---|---|---|
| 간병 시작 24시간 이전 | 경계 시점·환불·이용 제한 기준 | 정책 대조 전 |
| 간병 시작까지 24시간 이내 | 위약금·계산 근거·이용 제한 | 정책 대조 전 |
| 간병 진행 중 | 사용 기간·남은 기간·차감·환불 | 정책 대조 전 |

정확히 24시간인 경계와 적용 비율은 임의로 결정하지 않는다.

## 환불 안내 화면 실험 데이터 (2026-10-29)

기존 시안의 고정 실험 데이터다. 실제 서비스의 확정 정책으로 표현하지 않는다. 24시간 경계와 다른 시점의 비율은 여전히 정하지 않는다. 데이터 원본은 [cancellation-refund.json](../../fixtures/cancellation-refund.json)이다.

| 항목 | 값 | 비고 |
|---|---:|---|
| 취소 시점 | 간병 시작 18시간 전 | 이 한 케이스만 다룬다 |
| 신청 제한 | 7일 | |
| 결제 금액 | 3,158,400원 | 환불 계산의 출발 금액 |
| 위약금 계산 기준액 | 2,600,000원 | 위약금 비율을 적용하는 금액. 결제 금액과 다르다 |
| 위약금 | 52,000원 | 위약금 계산 기준액 × 2% |
| 환불 예정액 | 3,106,400원 | 결제 금액 − 위약금 |

화면 구성(선택 UI 없음, P01·P02): 적용 조건(취소 시점·위약금 발생·신청 제한) → 계산 근거(기준액·비율·위약금) → 환불 내역(결제 금액·위약금 차감) → 환불 예정액. 하단 버튼은 이동 ‘취소 사유 선택하기’다(P04). 취소 사유 입력·완료·실제 취소/환불 연동은 이번 범위에서 제외한다.

확정 전에 적용 정책, 차감 근거, 최종 환불 예정액을 보여준다. [공통 금액 확인 패턴](../patterns.md)을 참조하고 실제 요금 정책은 이 문서에서 별도로 정의한다.

화면·컴포넌트 재사용·실제 조작 검증은 미실행이다. 결과는 [취소 검증 기록](../../validation/cancellation.md)에 남긴다.
