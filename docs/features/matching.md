# 지원자 비교와 매칭 확정

상태: 기능 문서 골격. 이 저장소의 화면 구현·검증은 미실행.

## 기존 문제와 방향

기존 선착순 자동 매칭에서는 보호자가 지원자를 비교하고 환자에게 맞는지 확인하기 어려웠다. 여러 지원자의 경력과 관련 경험을 비교하고 보호자가 직접 선택하도록 설계했다.

예정 흐름: 조건 확인 → 지원자 탐색 → 후보 비교 → 조건 재확인 → 매칭 확정.

## 추가할 내용

| 항목 | 현재 상태 |
|---|---|
| 모집 중·지원자 없음·선택 대기·확정 상태 | 세부 명세 작성 전 |
| 선택 후 다른 지원자와 간병인 앱에 미치는 영향 | 구현 기준 확인 필요 |
| 필터·정보 우선순위와 실제 컴포넌트 | 구현 전 |
| 과업별 기대 결과와 증거 | 미실행 |

공통 역할·상태는 [product.md](../product.md), 공통 UI는 [design-system.md](../design-system.md)를 참조한다. 개별 케이스는 이 문서의 표로 추가한다.
