# 결제 정보 확인·비용 상세

상태: 시안 범위 명세(2026-10-29). `/payment`에 구현하고 브라우저 검증함([PY-B-20261029-01](../../validation/runs/PY-B-20261029-01/run.md)). 실제 결제는 연결하지 않는다.

사용자 질문: 무엇을 신청했는가? 최종으로 얼마를 결제하는가? 그 금액은 어떻게 계산됐는가?

공통 기준은 [금액 확인 패턴](../patterns.md)(P-AMOUNT-01 v2.1)과 [디자인 기준](../design-system.md)을 따른다. 이 문서에는 결제 화면에만 해당하는 조건을 적는다.

## 필수 요구사항

| ID | 구분 | 요구사항 |
|---|---|---|
| PY01 | 신청 정보 | 본문에서 환자 정보, 간병 유형과 중증도, 간병 일정을 확인할 수 있다. |
| PY02 | 결제 금액 | 하단에 최종 결제 예정 금액과 ‘결제하기’ 버튼을 고정한다. 본문을 스크롤해도 하단 영역은 유지되고 본문을 가리지 않는다. |
| PY03 | 상세 열기 | 하단 금액 옆 펼치기 버튼을 누르면 비용 상세 바텀시트를 연다. |
| PY04 | 비용 상세 | 바텀시트에서 평일·주말 단가, 일수별 비용, 보험료, 수수료를 확인한다. |
| PY05 | 상태 유지 | 상세를 열고 닫아도 신청 정보와 결제 금액은 바뀌지 않는다. |

## 화면 구성과 동작

| 영역 | 구성 | 동작 |
|---|---|---|
| 본문 | 환자 정보 → 간병 유형·중증도 → 간병 일정(기간, 평일 22일·주말·공휴일 8일) | 스크롤로 확인. 입력·수정 기능은 없다 |
| 하단 고정 | ‘결제 예정 금액’ 라벨과 금액, 펼치기 버튼, ‘결제하기’ 버튼 | 펼치기 → 바텀시트 열기. ‘결제하기’는 시안 범위 밖이라 실제 결제를 수행하지 않는다 |
| 비용 상세 바텀시트 | 평일·주말 단가 → 평일·주말 일수별 비용 → 간병비 합계 → 보험료 → 플랫폼 수수료 → 결제 예정 금액 | 닫기 버튼·배경 누르기로 닫는다. 닫으면 열기 전 화면 상태로 돌아간다 |

## 공통 패턴 적용

| 규칙 | 결제 화면에서의 적용 |
|---|---|
| P01·P02 | 선택이 없는 금액 확인 화면이다. 적용 조건(신청 정보·일정)과 최종 금액을 함께 보여주고, 계산 근거는 펼치기로 바로 열 수 있게 한다. |
| P03 | 결제 전 포함 항목(일수별 비용·보험료·수수료)과 근거(단가 × 일수)를 바텀시트에서 확인한다. |
| P04 | ‘결제하기’는 최종 행동이다. 펼치기 버튼은 상세 보기(이동)이며 결제와 구분한다. |
| P05 | 최종 금액은 ‘결제 예정 금액’ 라벨과 accent 강조. 상세 항목은 기본색. |
| P06 | 하단 금액과 바텀시트 금액은 같은 계산 결과를 쓴다. 간병비 조정과 같은 계산 경로(`calculateCarePrice`)를 인상률 0%로 사용하고 계산 정책은 바꾸지 않는다. |
| P07 | 바텀시트 열기·닫기와 본문 확인만으로는 신청 정보·결제 금액·결제 상태가 바뀌지 않는다. |
| 시각적 구성 | 최종 금액은 `AmountSummary`의 표시 기준, 상세 내역은 `DetailLine` 정렬, 간격은 `semantic.space`를 따른다. 공통 토큰·컴포넌트는 변경하지 않는다. |

## 금액 데이터

[care-price.json](../../fixtures/care-price.json)의 인상 전(0%) 값을 그대로 사용한다. 실험 데이터이며 실제 결제 정책이 아니다. 수수료 10%는 [간병비 조정 A03·A04](price-adjustment.md#이번-실험에만-사용하는-가정)의 실험 가정이다.

## 미정·미확인 항목

| 항목 | 상태 |
|---|---|
| 환자 정보·간병 유형·중증도·일정 날짜의 표시 값 | 미정. 저장소 fixture에 없다. 구현 시 실사용자 정보가 아닌 가상 데모 값을 쓰고 출처를 기록한다. 중증도 등급 체계는 확인하지 않았다 |
| 바텀시트 컴포넌트 | 공통 컴포넌트가 없다. 공통 컴포넌트를 바꾸지 않는 조건이므로 화면 안에서 구현하고, 공통화 여부는 따로 판단한다 |
| P04 확정 버튼 문구 | 공통 패턴의 확정 예시는 ‘{금액}원으로 ○○하기’다. 이 화면은 금액을 버튼 옆에 따로 두고 버튼 문구를 ‘결제하기’로 정했다. 패턴과의 차이로 기록한다 |
| 결제 수단·약관 동의·결제 실패 | 이번 범위 밖 |
