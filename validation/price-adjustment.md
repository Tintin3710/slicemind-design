# 간병비 조정 검증 기록

상태: S01~S09 전부 미실행. 현재 파일·fixture 준비를 화면 검증 결과로 해석하지 않는다.

## 검증할 것

- AI가 [공통 패턴](../docs/patterns.md)을 실제 화면에 적용하는가?
- 금액과 화면 간 상태가 [fixture](../fixtures/care-price.json)와 일치하는가?
- 공통 컴포넌트·토큰을 실제 코드에서 참조하는가?

## 문서 제공 여부를 비교할 때

A 조건에는 기능 요구사항과 같은 fixture만 제공한다. B 조건에는 공통 패턴·UI 기준·토큰을 추가한다. 별도 깨끗한 세션·폴더에서 같은 제작 요청·모델·데이터·참조 이미지·뷰포트를 사용한다. 최초 결과를 보존한 뒤 동일 기준으로 검토한다. 한 번의 생성은 사례 비교이며 일반적인 성능 향상 증거가 아니다.

## 결과 남기기

[실행 기록 양식](run-template.md)을 복사한다. 규칙 ID, 적용·누락, 실제 코드·화면 위치, 오류, 수정, 재검증을 남긴다. 사용자 이해도와 운영 지표는 별도 검증이 필요하다. 고객 반응을 AI가 생성해 채우지 않는다.
